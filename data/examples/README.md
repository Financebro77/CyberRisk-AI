# Synthetic Example Data

All files in this directory are **SYNTHETIC DEMONSTRATION DATA**.

They are fictional, generated examples for documentation and tutorials only:

- No real company is represented.
- No real person, email, phone number, or address is present.
- No confidential or licensed dataset is present.
- No real cyber insurance policy is described.

The examples exist so you can see the input format CyberRisk AI expects
without ever uploading or inventing client data. Replace every field with
your own data before running a real assessment.

Files:

| File | Purpose |
|---|---|
| `../examples/healthcare_case.json` | A complete fictional company brief: industry, revenue, cyber controls, and loss scenarios. |
